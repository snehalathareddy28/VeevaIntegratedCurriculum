## Jira – Practical QA & Agile Project Management

### Overview
Hands-on practice with Jira Software using a Student Management project. Worked with Scrum boards, sprint planning, issue tracking, QA dashboards, and bug reporting.

### Skills Practised
- Jira project and dashboard management
- Scrum backlog management
- Sprint planning and active sprint tracking
- Creating and managing tasks and bugs
- Bug reporting with reproduction steps
- Documenting expected and actual results
- Issue priority, status, labels, and assignee management
- Tracking defects using Jira dashboards and filters
