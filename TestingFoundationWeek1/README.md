# Testing Foundation - Week 1

## Learning path

| Order | Focus area | Topics | Hands-on outcome |
|---|---|---|---|
| 1 | Testing foundations | Fundamentals of testing; Quality Assurance (QA); System Integration Testing (SIT); User Acceptance Testing (UAT) | Explain the purpose of testing and distinguish QA, SIT, and UAT. |
| 2 | Software Development Life Cycle | Requirements, design, coding, testing, and deployment; Agile vs. Waterfall | Describe the SDLC stages and compare the two delivery approaches. |
| 3 | Testing and collaboration tools | JIRA for bug tracking; XRay for test case management; Confluence for documentation | Navigate the tools and understand how teams track work, tests, and knowledge. |
| 4 | Development setup and Java basics | IntelliJ IDEA setup; introductory Java programming | Set up a development environment and write basic Java code. |
| 5 | Test lifecycle with XRay | Create, organize, and execute tests; track execution results | Complete a test lifecycle exercise using XRay. |
