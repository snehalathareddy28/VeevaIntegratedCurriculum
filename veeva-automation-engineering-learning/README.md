# Veeva Automation Engineering Learning

A structured learning workspace for building automation engineering skills, from testing fundamentals and Java through frameworks, DevOps, cloud, AI, databases, and Linux.

## How to use this workspace

- Follow [ROADMAP.md](ROADMAP.md) for the recommended learning sequence.
- Update [PROGRESS.md](PROGRESS.md) as topics and exercises are completed.
- Record day-to-day learning in `daily-logs/`.
- Summarize outcomes, gaps, and next steps in `weekly-reviews/`.
- Keep practice work in the relevant learning module; use `projects/` for end-to-end exercises.
- Store reusable references in `resources/`.
