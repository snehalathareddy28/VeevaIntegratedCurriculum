# Java Streams API — Functional Data Processing

**Date:** 1 November 2026  
**Focus:** Declarative data processing using Java Streams

## Objective
Review the Streams API to process collections through readable pipelines without requiring repetitive manual iteration.

## Technical Areas Reviewed
- Stream creation from collections.
- Intermediate operations: `filter()`, `map()`, `sorted()`, and `distinct()`.
- Terminal operations: `collect()`, `forEach()`, `count()`, and `reduce()`.
- Lazy evaluation of intermediate operations.
- Stream pipelines and operation chaining.
- Difference between collections and streams.

## Practical Application
Example — filtering and transforming student data:

```java
import java.util.List;

public class StudentStreamDemo {
    public static void main(String[] args) {
        List<Integer> marks =
            List.of(45, 78, 90, 62, 35, 88);

        List<Integer> qualifiedMarks = marks.stream()
            .filter(mark -> mark >= 60)
            .sorted()
            .toList();

        System.out.println(qualifiedMarks);
    }
}
```

**Processing flow:**

`Collection → Stream → Filter → Sort → Result`

## Engineering Takeaways
- Streams provide declarative data-processing pipelines.
- Intermediate operations transform or filter data.
- Terminal operations trigger stream processing.
- Lazy evaluation avoids executing intermediate operations until a terminal operation is invoked.
- Streams improve readability for many collection-processing tasks.

**Outcome:** Strengthened functional-style data processing for filtering, transforming, and aggregating application data.
