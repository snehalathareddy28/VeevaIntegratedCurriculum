# Core Java

This module contains a weekly learning overview, dated learning notes, and a
nine-day hands-on practice sequence.

- [Core Java weekly overview](WEEK-2-CORE-JAVA.md)
- [Daily learning logs](Daily_logs/)

## Learning sequence

1. [Day 01 – Java Fundamentals](Day-01-Java-Fundamentals/README.md)
2. [Day 02 – Methods and Arrays](Day-02-Methods-Arrays/README.md)
3. [Day 03 – Encapsulation and Inheritance](Day-03-Encapsulation-Inheritance/README.md)
4. [Day 04 – Polymorphism and Abstraction](Day-04-Polymorphism-Abstraction/README.md)
5. [Day 05 – Collections](Day-05-Collections/README.md)
6. [Day 06 – Streams and Lambda](Day-06-Streams-Lambda/README.md)
7. [Day 07 – Exception Handling](Day-07-Exception-Handling/README.md)
8. [Day 08 – Java I/O](Day-08-Java-IO/README.md)
9. [Day 09 – Student CRUD](Day-09-Student-CRUD/README.md)

Run the examples from their day folder with `javac ClassName.java` followed by
`java ClassName`. Day 09 has its own compile and run instructions.

## Requirements

- JDK 8 or later
- A terminal or Java IDE

The examples are intentionally small so you can change them, run them, and
observe the result while learning each concept.
