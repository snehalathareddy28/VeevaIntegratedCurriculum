# Learning Roadmap

Progress through the modules in order. Each module should combine concept review, hands-on practice, and a small checkpoint before moving on.

| Order | Module | Suggested checkpoint |
|---|---|---|
| 01 | Testing Foundation | Explain the SDLC and testing types; create and execute test cases; report a defect. |
| 02 | Core Java | Write small programs using core syntax, control flow, methods, collections, and object-oriented basics. |
| 03 | Advanced Java | Practice exceptions, generics, streams, and other advanced language concepts. |
| 04 | Maven Build Tools | Create and build a Maven project; understand dependencies and lifecycle phases. |
| 05 | Git Version Control | Use branches, commits, merges, and pull-request workflows safely. |
| 06 | Test Automation | Automate a simple application flow and produce useful assertions and reports. |
| 07 | Testing Frameworks | Organize and run automated tests with suitable testing frameworks. |
| 08 | BDD Cucumber | Express scenarios with Gherkin and connect steps to executable automation. |
| 09 | DevOps Jenkins | Configure a pipeline to build and run tests automatically. |
| 10 | Cloud AWS | Learn foundational cloud concepts and deploy or operate a small learning exercise. |
| 11 | AI Fundamentals | Understand core AI concepts and evaluate practical, responsible use cases. |
| 12 | Database SQL | Query and modify sample relational data using SQL. |
| 13 | Linux | Navigate the command line and use common files, processes, and scripting tools. |

## Study loop

1. Review the concepts for the current module.
2. Complete hands-on exercises and save the work in that module.
3. Record what you learned and any blockers in `daily-logs/`.
4. At the end of the week, summarize evidence, gaps, and the next focus in `weekly-reviews/`.
5. Update [PROGRESS.md](PROGRESS.md) based on completed work.
